Now I'll provide detailed monitoring and debugging solutions for your Alpine image build script timeout issue:

## **Problem Analysis**
The timeout (exit 124) occurs because the local CLI terminates after ~10 seconds while the remote `alpine-make-vm-image` process continues running. The issue is on lines 130-138 where the heavy Alpine image building happens.

## **Solution 1: Remote Logging with Tee**

Create a modified version that logs all output remotely:


## **Solution 3: Incremental Monitoring Script**

```bash
#!/bin/bash
# monitor-alpine-build.sh

REMOTE_HOST="root@192.168.0.33"
SSH_KEY="~/.ssh/id_ed25519_clarity"
LOG_FILE="/tmp/alpine-build.log"

echo "🔍 Monitoring Alpine build progress..."

# Function to check if build is running
check_build_status() {
    ssh -i $SSH_KEY $REMOTE_HOST "ps aux | grep alpine-make-vm-image | grep -v grep" 2>/dev/null
}

# Function to tail logs
tail_remote_log() {
    ssh -i $SSH_KEY $REMOTE_HOST "tail -f $LOG_FILE 2>/dev/null || echo 'Log file not found yet...'"
}

# Function to check build artifacts
check_artifacts() {
    ssh -i $SSH_KEY $REMOTE_HOST "ls -la /tmp/alpine-builder/ 2>/dev/null || echo 'Build directory not found'"
}

# Main monitoring loop
while true; do
    echo "==================== $(date) ===================="
    
    if check_build_status; then
        echo "✅ Build process is running"
        echo "📋 Latest log entries:"
        ssh -i $SSH_KEY $REMOTE_HOST "tail -20 $LOG_FILE 2>/dev/null || echo 'No logs yet'"
    else
        echo "⚠️ Build process not detected"
        echo "📁 Checking artifacts:"
        check_artifacts
        
        # Check if image was created
        if ssh -i $SSH_KEY $REMOTE_HOST "[ -f /tmp/alpine-builder/alpine-ssh.qcow2 ]"; then
            echo "🎉 Build appears to be complete!"
            break
        fi
    fi
    
    echo ""
    sleep 30
done
```

## **Solution 5: SSH with Keepalives and No Timeout**

