## Common Questions

**Q: How do I update the website?**
A: Login to admin panel, make changes, click save. Changes are live immediately.

**Q: How do I add a new service?**
A: Admin panel → Services → Add New → Fill form → Save

**Q: How do I see bookings?**
A: Admin panel → Bookings → View all bookings

**Q: How do I know if the website is working?**
A: Visit https://andub.go.ro - if it loads, it's working. Check https://andub.go.ro/metrics for detailed status.

**Q: What if something breaks?**
A: System automatically rolls back to last working version. You'll receive alert notification.

**Q: How do I update prices?**
A: Admin panel → Services → Edit service → Update price → Save

**Q: Can customers book on mobile?**
A: Yes! Website fully optimized for mobile devices.

**Q: Is customer data safe?**
A: Yes. Bank-level encryption, automated backups, enterprise security.
